## About

I'm studying Medical Sciences and Engineering at IIT Madras, and I build AI applications where language models meet real interfaces.

Most of my work starts from a practical problem and ends as a working app with an evaluation behind it:

- **Context and memory** — dictation that understands what you meant, and an assistant that decides what's worth remembering instead of storing everything
- **Voice-first interfaces** — streaming speech-to-text, LLM reasoning and text-to-speech, in the language the user actually speaks
- **Grounded AI** — systems that answer from your own material, cite the exact source, and refuse when the evidence isn't there
- **Agents** — multi-step pipelines where each stage has a clear job and every run is logged
- **Security and health** — authenticated encryption protocols, medical image segmentation, and ML models for patient-monitor alerts

I care about measuring what I build: if a project makes a claim, there's usually a test harness in the repo backing it up.
